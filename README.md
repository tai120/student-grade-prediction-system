# 学生成绩预测系统

基于机器学习(多元线性回归)的学生成绩预测与教学辅助系统, 蓝色主题, 共五大功能模块:

| 模块 | 说明 | 对应身份 |
| --- | --- | --- |
| 成绩预测 | 录入平时测验、作业、出勤、期中、课堂表现, 模型自动预测期末成绩与挂科风险概率 | 学生 / 教师 |
| 教学辅助 | 学困生预警名单、特征影响权重分析, 方便针对性辅导 | 教师 |
| 学生自查 | 学生录入自身数据, 提前预估期末水平, 自动生成查漏补缺建议 | 学生 |
| 数据可视化 | 成绩分布、预测vs实际散点、等级构成、班级指标雷达图等 | 全部 |
| 教学管理 | 班级教学质量对比、教学评级、自动生成管理建议, 支撑课程评估 | 教务管理员 |

## 运行方法

```bash
pip install -r requirements.txt     # 或: pip install flask numpy
python app.py
```

浏览器打开 <http://127.0.0.1:5000>, 选择身份进入系统(演示系统无登录密码)。

## 模型说明

- 特征: 平时测验、作业完成、出勤率、期中考试、课堂表现(0-100 分)
- 目标: 期末成绩
- 算法: 多元线性回归, 特征标准化 + 正规方程求解(奇异时岭回归兜底), 纯 numpy 实现
- 特征重要性: 标准化回归系数占比
- 挂科风险: 由预测分经 Logistic(sigmoid) 函数映射为 0-1 概率
- 评估: 80/20 划分训练/测试集, 首页展示 R² / MAE / RMSE

## 使用真实数据

用 Excel 打开 `data/students.csv`, 按相同列名追加或替换学生数据, 保存后重启服务即可。
模型每次请求自动重新训练, 数据改动即时生效。
